The Odin Project: Etch-a-Sketch game in a browser using DOM manipulation skills.  

Created the project based on the classic red toy I found on google.  

Used addEventListener, querySelector to trigger button functions.  

Drawing mode can be changed from hover to click&drag.  

Colouring mode can be random colour and black colour.  

It is an amazing task to enable me to manipulate the document loaded into the window and attach an event handler. I also capable to create new elements (grid size) and add them to the current element as children or reset the whole grid container.
